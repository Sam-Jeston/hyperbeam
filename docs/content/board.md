The **Board** is the team’s view of everything in flight. Each card is a [workstream](/concepts#workstreams).

## Stages

| Stage | Meaning |
|---|---|
| Scoping | Being shaped before anyone builds. |
| Building | Agents are at work. |
| In review | Waiting on people. |
| Done | Finished. Done work drops off the board after seven days; it stays reachable from **Activity**. |
| Archived | Hidden from the board. |

Move a workstream between stages from the stage menu on its page.

## Cards

Each card shows the workstream’s title, the agents working on it and what each is doing right now, a **Needs a reply** badge when an agent is waiting for input, how many pull requests it has produced, when it last changed, and who is involved.

Agents started without a workstream appear under **Agents not on the board**.

## A workstream’s page

- **Brief**: the context every agent added to the workstream is given. Write it the way you would brief a new colleague. Markdown works.
- **Agents**: every agent on it, with the workers a conductor started nested under it.
- **Discussion**: comments for the people on the team. Agents do not read this; message an agent from its own page.
- **Links**: pull requests and issues the agents produced.
- **Activity**: what happened on this workstream, newest first.

## Activity

**Activity** in the sidebar lists what people and agents have done across the team, grouped by day: agents started and finished, workstreams moved, comments, and pull requests opened.
